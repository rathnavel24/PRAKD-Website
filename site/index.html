How we work

A simple path from idea to production

  1. 1

    Understand

    A short call about the problem, the users and the constraints. You get a written scope and a price before any work starts.

  2. 2

    Build

    We work in small milestones and show you running software every week, so there are no surprises at the end.

  3. 3

    Launch

    Automated deploys, backups and monitoring are set up before go-live, not bolted on afterwards.

  4. 4

    Run

    We can keep operating it for you, or hand over clean code and documentation to your own team.

Principles

Robust is a habit, not a feature

Monitored by default
